# 01 - Video Mapping & NLP Concept Formulation

## Overview
This module outlines the foundational transition from traditional E-Commerce Sentiment Analysis (from standard NLP video tutorials) to an **Academic Stress & Student Voice Intelligence System**.

### Conceptual Mapping

| Video Tutorial Concept (E-Commerce) | MindTrack AI Adaptation (Academic Stress) |
| :--- | :--- |
| Customer Product Reviews | Student Course Evaluations, Forum Reflections, Feedback |
| Binary Sentiment (Positive / Negative) | Multi-Class Cognitive States (High Stress, Overload, Frustration, Disengagement, Positive, Neutral) |
| Star Ratings (1-5 Stars) | Stress Severity Index (0 - 100 scale) & Urgency Classification |
| Feature Keywords (Battery, Screen, Price) | Aspect Mining (Mental Well-being, Workload, Examination, Teaching, Support) |
| Recommendation to Buy / Skip | Automated Supportive Coping Strategies & Counselor Referral Escalation |
